Bulma

Flexbox Based
v1.0.0

Bulma - современный CSS фреймворк, основанный на Flexbox. Чистый CSS, без JavaScript зависимостей.

🎨 Особенности Bulma

  • Основан на Flexbox
  • Чистый CSS - нет JavaScript
  • Модульная архитектура
  • Современный и чистый дизайн

Преимущества

🎯 Простота

Интуитивно понятные классы и структура

📦 Модульность

Импортируйте только нужные модули

🚀 Производительность

Нет JavaScript, только CSS

🎨 Кастомизация

Легко настраивается через SASS переменные

Ключевые компоненты

📐 Grid System

Мощная система сеток на Flexbox

.columns .column .column

📱 Responsive

Мобильные-first responsive классы

.is-mobile .is-tablet .is-desktop

🎨 Elements

Кнопки, формы, типографика

.button .input .title

🧩 Components

Навигация, карточки, сообщения

.navbar .card .message

Пример кода

// Установка через npm npm install bulma // Или через CDN <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bulma@1.0.0/css/bulma.min.css"> // Пример навигации <nav class="navbar" role="navigation"> <div class="navbar-brand"> <a class="navbar-item" href="#"> <img src="logo.png"> </a> </div> </nav> // Пример кнопки <button class="button is-primary">Кнопка Bulma</button>
