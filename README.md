# Site
Создание сайта
CSS Фреймворки - это образовательный веб-сайт, созданный для изучения и сравнения современных CSS фреймворков. Проект демонстрирует практическое применение frontend-технологий и реализует полностью адаптивный дизайн в ретро-стиле NES.

Установка и запуск
Скачайте файлы проекта

Вариант 1: Открыть напрямую в браузере
Вариант 2: Использовать локальный сервер
Вариант 3: Использовать Live Server в VS Code
