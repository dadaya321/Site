О проекте

Этот образовательный проект создан для изучения современных CSS фреймворков и их сравнения.

🎯 Цели проекта

  • Изучение популярных CSS фреймворков
  • Сравнение их возможностей и подходов
  • Демонстрация использования NES.css
  • Создание полнофункционального адаптивного сайта

Технологии проекта

🖥️ Frontend

  • HTML5 - семантическая верстка
  • CSS3 - кастомные стили
  • NES.css - CSS фреймворк
  • JavaScript - интерактивность

⚙️ Инструменты

  • VS Code - редактор кода
  • Git - контроль версий
  • Chrome DevTools - отладка
  • W3C Validator - проверка кода
