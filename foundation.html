Foundation

Enterprise Level
v6.9.0

Foundation - профессиональный frontend фреймворк для создания адаптивных веб-сайтов и приложений enterprise-уровня.

🏢 Особенности Foundation

  • Профессиональный enterprise уровень
  • Мощная система сеток
  • Богатая библиотека компонентов
  • Flexible и настраиваемый

Архитектура Foundation

🎯 Modular Scale

Типографика на основе модульной шкалы

$header-sizes: ( small: (...), medium: (...) );

📐 XY Grid

Продвинутая 2D система сеток

.grid-x .cell .cell

🔧 Motion UI

Библиотека CSS анимаций и переходов

@include mui-slide( in, right, 100% );

🎨 Customization

Глубокая кастомизация через SASS

$primary-color: #1779ba; $accordion-background: #fff;
